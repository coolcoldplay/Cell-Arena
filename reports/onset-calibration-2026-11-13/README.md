# 发生发展免疫校准与抗原谱系显示（2026-11-13）

## 结论与边界

默认情景确实很少出现激活免疫，且抑制样状态可以早于任何死亡。旧的 `reports/immune-genetics/scenarios-final-onset.json` 已有类似结果；本次按网页默认 240×180、1.5× 精细度重新实跑确认，不把旧报告当作当前测量。

- 初始全部为正常组织，零激活是合理的初态；持续很少激活则受本模型的有限受体库、抗原匹配、营养和增援共同限制，不能推断真实肿瘤通常如此。
- 正常细胞存活时，`max(stress,damage)>0.06` 就产生来源标记的损伤信号；环境死亡需 `stress>=1`。免疫细胞积分的是局部信号，不是全局死亡计数。蓝色早于死亡不是计数漏报。
- 蓝色是同一物理免疫类型的抽象抑制功能状态；不是实测 Treg 数量，也不是 CD8 CTL 通常直接转分化为 CD4 Treg 的断言。
- 基线 6,000 MCS 四个种子中，三个全程未激活，另一个仅出现过一颗；四次均先转蓝后发生首例死亡。实际接触评估约 92%–100% 不匹配，而且大多伴有营养受限。各限制可同时存在，百分比不能相加。
- 只降低抑制、只增强启动/血管到达，或缩短抽象抗原码，都没有让这四个种子产生持续活跃的免疫杀伤。因此没有把后两种“看似合理”的设置作为修复发布，也没有绕过匹配、呈递或接触门槛。

## 发布的参数调整

| 设置 | 原发生发展 | 新发生发展 | 新随机开局范围 |
|---|---:|---:|---:|
| 损伤转抑制倍率 | 3.5 | 1 | 0.5–1.5，步长 0.25 |
| 损伤退激活倍率 | 1.2 | 1 | 0.7–1.3，步长 0.1 |
| 抑制信号分泌 | 1.5 | 1 | 0.75–1.25，步长 0.25 |
| 抑制作用强度 | 1.3 | 1 | 0.8–1.2，步长 0.1 |
| 正常损伤暴露记忆 | 200 MCS | 600 MCS | 400–800 MCS，步长 100 |

恢复速度仍为 1.5，初始免疫响应资格仍为 65%，候选谱仍最多 32，抗原码仍 6 位。损伤记忆增大会放慢暴露建立，也会放慢离开损伤区后的记忆消退，不是单向加速恢复。这些是演示校准参数，不是人体正常范围。冷/热情景不采用这一组新抑制参数。

修订组的抑制细胞时间占比由原四种子的 9.5%–15.0% 降到 1.7%–3.9%；这是减轻过强的早期抑制倾向，不是修好了全部免疫响应。额外四个种子仍有低响应或较多抑制的轨迹；没有强制先死亡、强制变红或指定胜负。

## 实验方法与复现

脚本：[`scripts/probe-onset-immunity.mjs`](../../scripts/probe-onset-immunity.mjs)。WASM 后端，循环边界，240×180 模型区域，1.5× 格点精细度，35 MCS 机械预热。所有生物学逐步执行；每 500 MCS 保存完整计数及候选库/驻留受体覆盖，逐 MCS 积分免疫状态和记录首次事件。观察器不消耗随机数、不制造目标、不指定受体。

`activeCellMcs / immuneCellMcs` 和 `suppressiveCellMcs / immuneCellMcs` 表示存活免疫细胞在该状态下占全部免疫细胞时间的比例，不是峰值、最终比例或患者人群发生率。首例死亡同时记录“开始死亡”和“实际清除”，避免把动画中的死亡漏算。

```sh
node scripts/probe-onset-immunity.mjs --label=revised --until=12000
node scripts/probe-onset-immunity.mjs --label=original-replay --until=12000 --settings-file=reports/onset-calibration-2026-11-13/baseline.json
node scripts/probe-onset-immunity.mjs --label=holdout --seeds=5,2026,3735928559,4294967295 --until=12000
node scripts/probe-onset-immunity.mjs --label=random --scene=random --until=6000
```

每份 JSON 保存源文件与 WASM 的 SHA-256、实际参数、种子、分辨率和事件。原始基线为 Git `2a55e9e` 加本目录 `baseline-pixel-index.patch`（索引默认关闭）。后续显示观察器不影响动力学；`baseline-replay-final.json` 用最终源码加完整旧参数复核种子 17 的 6,000 MCS 生物学记录。并发运行的 `elapsedMs` 仅为运行记录，不作为性能对照。

各组：

- `baseline.json`：4 种子 × 6,000 MCS；`baseline-long.json`：相同 4 种子 × 12,000 MCS。
- `suppression-only.json`：发布的五项抑制设置，4 × 12,000 MCS。
- `response-only.json`：仅初始响应资格 85%、启动 2×、血管到达 2×，4 × 12,000 MCS；未采纳。
- `length4.json`：仅将抗原码改为 4 位，4 × 12,000 MCS；未采纳。
- `revised-holdout.json`：新默认，另 4 个种子 × 12,000 MCS；`revised-random.json`：新随机范围，4 × 6,000 MCS。

有限受体谱与低氧区免疫效能仍是模型限制。后续若继续校准，应分别测量候选覆盖、现有受体实际相遇、启动完成后能否穿过血管进入，以及局部代谢执行能力，不能将调整一个倍率或一个种子的改善当作已验证的普遍机制。

## 抗原—突变—遗传—免疫可视化

- **一个非自身抗原序列＋呈递通道对应一种稳定颜色**。父子代继承相同色段；不同来源但同一抗原也同色。无关性状突变不换色；抗原序列突变换色，遗传丢失移除对应段。
- 肿瘤及癌前细胞的真实外边缘显示对应色段；多个抗原按质心角度分段，各段深浅对应本抗原当前呈递。低呈递保留浅色身份，未把它误画成有效刺激。
- 免疫细胞核按**实际形变轮廓的弧长**等分，列出该稳定受体可匹配的当前非自身抗原。重复抗原只列一次；不兼容的通道不匹配。没有匹配时保留原核色。
- 核弧展示亲和力潜力，不表示已经接触、已经启动或有足够呈递。静息、激活、抑制仍由胞体颜色表示。绘制层不向模拟提供远处目标，也不改变受体、RNG、细胞几何或动力学。
- 同一映射用于 WebGL 胞体轮廓、Canvas 回退及共用的核弧覆盖层。截图/录像使用该画布。显示开关、图例、选中详情和中英文说明一起更新。
- 固定色值不是无限可辨的编码；抗原很多时可能色调相近，图例给出稳定标签和具体序列/通道，选中详情列出全部匹配。

[`visual-fixture.json`](visual-fixture.json) 是人为构造的显示验证夹具，可导入网页；包含两个同抗原细胞、一个可交叉识别的突变体、另一呈递通道及不匹配免疫细胞，不用于发生发展校准。[GPU 截图](antigen-lineages-gpu.png)、[Canvas 截图](antigen-lineages-cpu.png)、[浏览器检查](visual-checks.json)。

## 真实生物学能支持什么

1. 早期病灶并非普遍没有免疫激活。肺鳞癌多阶段研究在侵袭前同时观察到免疫激活和逃逸；这是组织与阶段相关的共同演化，不能只选其中一种作为“真实常态”。[Mascaux 等，Nature 2019](https://pubmed.ncbi.nlm.nih.gov/31243362/)。
2. 肺腺癌及其前驱病变研究观察到随进展出现较弱的细胞毒反应和更强免疫调节，支持状态随阶段改变，但不验证本模拟的转换概率或细胞比例。[Dejima 等，Nature Communications 2021](https://pmc.ncbi.nlm.nih.gov/articles/PMC8113327/)。
3. 抑制性细胞的募集并没有统一的“必须先发生细胞死亡”门槛。例如卵巢癌研究中，肿瘤细胞及微环境巨噬细胞产生 CCL22，参与 Treg 募集。它支持信号驱动的抑制途径，不证明本项目“正常压力直接让 CTL 转蓝”的具体规则。[Curiel 等，Nature Medicine 2004](https://www.nature.com/articles/nm1093)。

因此：模型中“无死亡先转蓝”有明确的代码原因；真实免疫抑制也可在不以死亡为触发门槛的机制下发生。但“几乎不激活、蓝色先出现”是否占多数，不能从这个未针对特定癌种校准的演示回答。MCS 不是临床时间，蓝色不是细胞谱系鉴定。
