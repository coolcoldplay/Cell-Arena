# 大画布性能优化实测

2026-11-18，在 Apple M5、32 GiB、macOS arm64、Node 24.22.1 上对照提交 `14b818034c94746b1a1db5a878ec620c2649b0d2` 和本地构建。使用热肿瘤场景、周期边界和相同生物学参数。最大世界为 512 × 384，精细度 2×，物理格点 1024 × 768，测试期间约 850 颗细胞。各次运行的原始单位、窗口统计和状态摘要保存在[测量数据](measurements.json)。

## 用户能感受到的变化

| 条件与指标 | 原版 | 优化后 |
|---|---:|---:|
| 最大世界，种子 17，从构造模型到 WASM 就绪 | 4.67 秒 | 2.08 秒 |
| 同场景，预热后模拟进程驻留内存 | 831 MiB | 395 MiB |
| 同场景，预热后 JavaScript 已用堆 | 447 MiB | 25 MiB |
| 默认世界，种子 17，预热后模拟进程驻留内存 | 297 MiB | 140 MiB |
| 最大世界，种子 17，播放快照生成并通过消息端口接收的均值 | 11.14 毫秒 | 5.99 毫秒 |
| 同一快照路径，种子 29 | 11.08 毫秒 | 5.87 毫秒 |
| 最大世界，种子 17，每次更新转移的二进制缓冲均值 | 3.57 MiB | 2.60 MiB |
| 默认世界，种子 17，同一快照路径均值 | 2.65 毫秒 | 1.49 毫秒 |

启动计时包含原有的 35 步形变预热和安装 WASM。之后再推进 32 个完整 MCS，触发垃圾回收，再读取驻留内存和已用堆。两版分别使用独立进程。驻留内存包含 Node 运行时，不代表手机浏览器的内存峰值。

快照对照在同一份演化中的状态交替调用旧版和新版打包逻辑，每个被测 MCS 各发一帧，使用真实的 Node 消息端口和可转移缓冲区。表中用时包括打包、序列化、接收和恢复显示帧，不含屏幕绘制；二进制字节数只统计转移的数组。最大和默认世界各计时 96 帧，小世界 64 帧。最大世界种子 17 的交付 P95 从 12.49 毫秒降到 6.42 毫秒。

## 模拟推进和卡顿

最大世界种子 17 的配对测试覆盖 480 个完整 MCS。单步 P99 从 48.75 降至 23.23 毫秒，超过 50 毫秒的步从 3 次降至 0 次。其中 10 次细胞移除的平均耗时从 32.13 降至 0.42 毫秒，平均推进从 66.65 增至 68.01 MCS/s。精细度 4× 的 960 × 720 格点场景中，单步 P99 从 31.64 降至 15.79 毫秒。该窗口只有 1 次分裂，不能单凭这一次估计分裂的长期耗时分布。

纯模拟吞吐会随演化阶段变化。在独立进程、每次 240 步的固定窗口里，最大世界种子 17 从 69.1 变为 68.5 MCS/s，种子 29 从 69.7 变为 64.5 MCS/s。种子 29 的另一组 480 步交替配对窗口从 67.25 变为 67.77 MCS/s，P99 从 31.65 降至 25.05 毫秒。纯 JavaScript 回退的 48 步短测中，种子 17 从 9.7 增至 22.6 MCS/s。

## 实现

- 各尺寸的 JavaScript 格点都用固定偏移取得内部邻居，只缓存边界行。保留 Artistoo 的邻居顺序、实体边缘和周期回绕。使用旧模型接口显式索取完整邻接表时，才构建相应数组。[模型](../../src/model.js)
- 物理格点数达到 262,144 时，自动维护每颗细胞的像素成员表。清除和分裂只访问相关胞体，在需要顺序时还原 Artistoo 的遍历顺序。运行中降低精细度会按新格点数重新选择，显式指定的索引开关继续有效。[格点转换](../../src/grid-transfer.js)
- 播放帧按版本复用墙体、障碍掩膜和所有环境通道。常见相同的细胞属性只传一个值，随细胞变化的数值属性用双精度列传送。检查某颗细胞时只展开该行。主线程按最近收到的帧复原状态，版本失配会请求完整帧。暂停、编辑和导出仍可取到当前完整状态。公开快照的墙和场按需提供独立副本。[帧协议](../../src/presentation-frames.js) · [Worker](../../src/worker.js)
- WebGL 复用墙和环境纹理。关闭抗原轮廓时跳过抗原图集生成和上传。Canvas 2D 回退按需计算胞体颜色。场版本相同时，复用已合成的环境热图和信号图层。[GPU 绘制](../../src/gpu-renderer.js) · [场显示](../../src/display-fields.js)

## 正确性与设备验证

独立进程的最大世界两种子、默认世界和纯 JavaScript 回退，在各自的相同 MCS 都得到相同状态摘要。摘要覆盖完整公开快照、细胞内部数据、形变与免疫两条随机数流、格点活动、细胞占据、接触、边界顺序和谱系。额外的配对测试逐窗口核验状态。快照对照另外抽查每个细胞的全部属性、格点、场和统计。

455 项自动化测试通过，两个单文件入口和构建清单校验通过。浏览器验证覆盖选中细胞分裂后追踪两个后代、播放中读取检查面板、暂停切换抗原图层、墙与环境编辑、恢复完整帧和实验导出。390 × 844 模拟视口运行最大格点，WebGL 路径成功导出 859 颗细胞；强制 Canvas 2D 回退时，胞体、胞核和环境层产生不同像素输出，分裂和导出正常。

浏览器验证使用 M5。该自动化窗口即使报告前台和可见，动画回调间隔仍约 1.00–1.02 秒。真实显示 FPS、手机持续运行时的温升与内存，以及超过当前 1024 × 768 格点的容量，需要前台真机单独测量。当前播放帧仍逐帧转移完整细胞 ID 和活动栅格，适合在下一轮用变化区域编码继续降低传输量。

## 复测

在仓库根目录使用 Node 24，从本地 Git 历史读取上述基线提交。

```sh
node scripts/build.mjs
node scripts/verify-build.mjs
node --test tests/*.test.mjs
node scripts/benchmark-frame-stream.mjs maximum 17 96
node --expose-gc scripts/benchmark-frame-stream.mjs maximum 17 240 --startup=before
node --expose-gc scripts/benchmark-frame-stream.mjs maximum 17 240 --startup=after
node --expose-gc scripts/benchmark-pixel-index.mjs --baseline=14b818034c94746b1a1db5a878ec620c2649b0d2 --child=maximum:17 --pairs=3 --steps=160 --warmup=64
```

将种子换为 29 可复测第二个最大世界。第一组脚本支持 `default`、`small` 和 `maximum`，启动测试加 `--js` 可测纯 JavaScript。配对脚本的 `--child=fine:17` 测试 4× 精细度。性能测试宜顺序运行。
