# 免疫拥堵、按情景随机与粗格点对照

2026-11-14；模型 `2026-11-immune-crowding-coarse-grid-9`，旧版对照 `ca1f63e`。本轮沿用 Artistoo / WASM CPM 和现有核区、连通性、接触识别、学习、代谢、周期、死亡与血管规则。

## 免疫团块为什么不动

已有修复包括免疫同类中性黏附、后缘回缩驱动、受限时周长软化、机械限制生长、受阻巡游及免疫同类分离。本次没有重复这些修改。

热肿瘤 320×240、1.5×、循环边界、种子 17 / 31 / 77、默认参数，35 MCS 预热后推进 8000 MCS。原版在病灶已清除后仍有携带抗原的免疫细胞释放招募信号。信号局部富集使趋化占优，也压低既有巡游记忆和分离权重；团块内部细胞在核区与最小面积约束下彼此顶住。这些细胞仍有良好能量和代谢效能、没有抗原接触目标，膜边界仍有少量更新，所以是机械拥堵，不是 Worker 卡死，也不是正在执行杀伤的正常停留。

修复仅对 **search 且无 targetID** 的免疫细胞，根据实际同类接触长度和当前机械压力降低局部趋化响应（最多降至原来的 1/5），从而恢复原有巡游／分离的作用。未改核区、最小面积、连通性或真实扫描／杀伤规则；没有传送、挤掉细胞、自动删除细胞或额外削弱招募信号。

每 10 MCS 采样胞核位置，250 MCS 为一个窗口。候选细胞必须至少 80% 的采样时间处于无目标搜索且 fitness > 0.5；“不动”指该窗口采样的累计核位移为 0，“近乎停滞”指相对窗口起点的最大位移小于 1 模型长度。周期边界按最短位移处理。此为离散采样指标，不排除两个采样时刻之间的短暂移动。

| 种子 | 原版不动的细胞窗口数 | 修复后 | 原版单窗口最多不动 | 修复后 | 原版终点免疫 | 修复后终点免疫 |
|---|---:|---:|---:|---:|---:|---:|
| 17 | 21 | 0 | 6 | 0 | 67 | 89 |
| 31 | 31 | 0 | 9 | 0 | 69 | 79 |
| 77 | 9 | 0 | 4 | 0 | 62 | 73 |

原版 96 个窗口中 18 个出现上述不动细胞；修复后为 0/96。原版近乎停滞的单窗口峰值分别 13 / 17 / 12，修复后为 0 / 1 / 0。六次运行终点均清除肿瘤；累计肿瘤杀伤原版 39 / 47 / 45，修复后 46 / 51 / 44。迁移变化会改变实际接触与后续扩增，因此不是逐步轨迹不变的性能优化。三种子样本不证明任意密度、种子均无拥堵。

## 当前情景内随机

手动随机与自动换局共用当前场景。设置抽样由独立初始化随机数生成器完成，不额外消费物理模拟随机流。冷热各自小幅抽样，保持抗原暴露、初始免疫、肿瘤周期、募集与运动的不同配置；发生发展沿用既有有界范围；迷宫保持物理墙；空白情景仍为空白并暂停。锁定值最后覆盖抽样结果。旧 `random` 情景的参数抽样顺序与范围保留，旧实验仍可导入。

新种子同时改变实际初始几何与遗传抽样。随机不会把热肿瘤切换为无肿瘤的发生发展场景。参数导出／历史回放保存实际抽样值，不依赖再次抽样。边界、区域、精细度默认锁定；全部锁定仍会生成新种子。

## 粗格点的含义和限制

改为拉杆，最低 **0.375×**、默认 1.5×、最高 4×，按区域长宽共同可用的整数格点步长对齐。例如 320×240 最低 0.375×，240×180 最低 23/60≈0.383×，512×384 最高 2×。迷宫最低 0.5×，避免未解析的墙隙。0.375× 相对默认只有 1/16 的 CPM 格点；0.5× 为 1/9，0.75× 为 1/4。细胞目标面积、核径和世界坐标按精细度缩放。普通情景的环境场维持同一模型空间尺度。迷宫环境场原有单格下限仍在，不能认为其扩散离散化跨档完全一致。

**精细度会改变模型演化，不只是画质。** 一个格点对应的面积、离散核区、膜接触、间隙通行和随机拷贝过程都会改变；连续缩放目标量不能使这些过程完全等价。同种子跨档也不是相同物理随机轨迹。粗档尤其不适合把单个细胞形态、瞬时迁移速度、接触次数或杀伤时刻直接与细档作数值比较。这里只开放空间预览，不宣称分辨率收敛或生物学等价。

相同热肿瘤参数、同样三个种子、320×240 和 8035 MCS，所有终点存活胞体连通且完整容纳胞核；0.5× 和 0.75× 没有观测到上面定义的不动或近乎停滞窗口：

| 精细度 | 终点肿瘤数（17 / 31 / 77） | 累计杀伤 | 终点免疫数 |
|---|---|---|---|
| 修复后 1.5× | 0 / 0 / 0 | 46 / 51 / 44 | 89 / 79 / 73 |
| 0.75× | 0 / 23 / 0 | 43 / 50 / 52 | 66 / 68 / 56 |
| 0.5× | 19 / 0 / 0 | 62 / 47 / 66 | 89 / 63 / 45 |
| 0.375× | 31 / 5 / 26 | 55 / 74 / 107 | 57 / 69 / 37 |

0.375× 三个种子分别有 5 / 22 / 5 个不动细胞窗口，单窗口最多 1 / 3 / 1 颗。仍可持续迁移、杀伤和扩增，但低于 0.5× 明确标为**极粗预览**。这个下限是当前测试支持的工程折中，不是数学或生物学意义上的最小网格。

存在不同清除／残留结局，不能将三个种子用作等价性证明或概率估计。粗档用于先找空间模式；需要定量结论时固定精细度、增加种子，再用更细格点做敏感性对照。**显示分辨率**是另一个控件：它只改渲染，可先降低它来减轻绘图负担，不会改变物理轨迹。

## 为什么没有继续降到 0.25×

短程的“胞体连通、核区完整、场有限值”检查不足以判定粗档可用。0.25× 在 500 MCS 初始化／机制检查中可以通过，但延长到 8035 MCS 后，三个种子分别有 561 / 654 / 623 个不动细胞窗口，最后 19/19、23/23、21/21 个健康搜索候选免疫细胞完全不动，累计杀伤仅 8 / 9 / 4。每颗免疫仅几个格点，离散核区、厚度和最小面积约束几乎封闭了迁移自由度。

进一步试过仅在极粗档放宽胞体厚度要求，杀伤增加，但仍有 267 / 342 / 181 个不动细胞窗口。该试验会改变机械机制且没有解决问题，**已全部撤回**，发布的 section-mechanics、C 源码和 WASM 与旧版相同。0.1875× 及更低还出现环境场空箱／非有限密度、血管无法正常成腔或初始化失败。失败试验的实际参数与哈希保存在 [rejected-coarse-prototypes.json](rejected-coarse-prototypes.json)，避免以后只凭短测试重复这些尝试。

## 运行中降低精细度

同一区域降低精细度时建立独立候选网格：按重叠面积投影、预留完整核区、连通扩展并保留每颗细胞的 ID／出生编号。保存生物学时间、细胞身份、遗传／抗原／学习记录、周期、剩余分裂额度、死亡过程、计数、历史和两条随机数流；长度与面积分别缩放，普通情景场浓度保留。轨迹同步换算坐标，历史保持同一回合，并记录切换时间和前后精细度。

几何只能近似：核位置对齐粗格点，无法解析的细小突起变为介质，目标生物量保留。墙取保守覆盖，不为成功转换抹去细胞或打通墙。如果核区、连通性、最小面积或区域尺寸无法保持，整次转换拒绝，原模拟不变。升档和改变区域仍重新开始。导出仍是参数实验，并非完整检查点；历史重跑恢复初始配方，不自动重放中途降档，导入会说明这个限制。

320×240、热肿瘤种子 17 在 4035 MCS、冷肿瘤种子 31 与发生发展种子 77 在 2035 MCS，分别从 1.5× 尝试 1 / 0.75 / 0.5 / 0.375×，再推进 500 MCS。12 次中 11 次转换成功，全部保留转换时细胞数，续跑后完整性通过；冷肿瘤到 1× 因细胞 #173 的投影无法满足约束而拒绝，同一源状态到其他三档成功。更细的目标档也不保证更容易转换，因为格点对齐不同。原始结果见 [grid-transfer.json](grid-transfer.json)；其中转换耗时与其他验证并行，不能用作独占性能基准。

全套 Node 回归 **444/444 通过**，无跳过，192.6 秒。网页实际操作也确认默认区域 1.5→约 0.383×、320×240 热肿瘤 1.5→0.375× 后时刻、细胞 ID／出生编号／谱系／周期、历史与回合编号保留，并能再推进 100 MCS。测试不会证明跨档物理等价。

随后追加世界尺寸小数舍入的连续降档回归，迁移／拉杆／历史／翻译共 22/22 通过，当前测试总数为 445。Ego 浏览器 16 项检查见 [browser-checks.json](browser-checks.json)，包括手动与自动场景内随机、锁、降档／升档、范围变化、迷宫及手机英文控件；手机是视口模拟，非实体手机性能测试。

## 独占速度对照

Apple M5、arm64、Node v24.22.1，WASM CPM 与 CPU 环境场。512×384 热肿瘤、种子 17，默认预热 35 MCS 后再推进 200 MCS，测量接下来 300 MCS；每档三次，交替运行顺序，取中位数。约 850 颗细胞，所有终点完整性通过。测量时未运行其他模拟或回归任务，网页处于暂停状态。逐次结果、硬件与源码哈希见 [coarse-benchmark.json](coarse-benchmark.json)。

| 精细度 | 真实格点 | ms / MCS | 相对默认加速 | 计算时间减少 |
|---|---|---:|---:|---:|
| 1.5×（默认） | 768×576 | 24.90 | 1.00× | — |
| 1× | 512×384 | 16.76 | 1.49× | 32.7% |
| 0.75× | 384×288 | 14.10 | 1.77× | 43.4% |
| 0.5× | 256×192 | 11.08 | 2.25× | 55.5% |
| 0.375×（极粗） | 192×144 | 9.28 | 2.68× | 62.7% |

这是纯模型推进速度，不含快照、绘图、交互，不等同于浏览器 FPS 或万细胞流畅性证明。格点降到 1/16 并没有加速 16 倍，因为逐细胞生物过程、环境场和接触等仍然计算，跨档的实际几何和接触轨迹也不同。相同精细度的拥堵修复是运动规则修正，不作为性能优化声称加速。
