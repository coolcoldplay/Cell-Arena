# 血管外直径上限与内皮退出周期

2026-11-13；在 `eaf3ea9` 基础上增加尺寸限制，模型修订 `2026-11-vessel-diameter-limit-8`。此前收紧修复触发及分裂额度仍不能保证血管最终尺寸；本次按用户新要求增加硬上限，替代此前不设固定管径上限的规则。本文长度、场浓度与 MCS 均为模型单位。

## 规则

- 新参数 `vesselMaxDiameter` 默认 **48**，表示包含管壁的外直径，手动范围 30–160。位置：「参数 → 微环境 → 血管、灌注与浸润 → 血管外直径上限」。默认及随机情景均使用 48；现有默认初始外直径为 36，因此仍有生长空间。精细度改变不改变模型单位的上限。
- 每条血管独立检查。参考外直径达到上限，或真实内皮总面积已经足以撑到该直径时，所属存活内皮统一保持 G0，取消 G1/S/G2/M 进度、修复驱动和尚未兑现的生长需求。面积门槛防止管径缓慢扩张期间继续积累分裂与胞体。
- 此限制同时约束 CPM 向外复制和参考半径；JS 与 WASM 内核都执行。不是只限制画面中的圆圈。分裂入口也检查，手动干预不能绕过尺寸限制。
- 状态按血管锁存，半径波动或收缩不能自动重启；手动提高上限才恢复增殖许可，仍需满足营养、空间和原有剩余分裂额度。提高上限不会补回额度。
- 调低上限立即停止超限血管的周期，已有胞体与管径连续回缩，不删除细胞或核区。尚在原界限外的胞体只能向内、不能继续向外扩张。回缩会改变管腔与灌注，并不保证保持满灌注。
- G0 不等于死亡；代谢、损伤、寿命、迁移和灌注计算继续执行。锁存后也不允许通过修复信号继续分裂，因此后续内皮丢失可能导致破损或功能下降。这是用户指定的尺寸控制规则，不宣称是实测微血管停周期机制。
