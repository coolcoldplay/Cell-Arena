# 发生发展与空间亚群对照

使用顶部文件图标导入，均从零肿瘤开始；固定种子 17、240×180、1.5×、循环边界、35 MCS 预热，关闭自动换局。建议观察至 16000–24000 MCS。它们保存初始参数，不是续跑检查点。

| 文件 | 用途 |
|---|---|
| [01-onset.json](01-onset.json) | 当前发生发展参数，观察独立癌变、真实肿瘤分裂与亚群演化。 |
| [02-no-division-mutation.json](02-no-division-mutation.json) | 相同初态，关闭分裂遗传突变；独立癌前／癌变与不同创始性状仍存在，不等于所有肿瘤完全同质。 |
| [03-no-immune-kill.json](03-no-immune-kill.json) | 相同初态，关闭杀伤执行；接触、学习和其他信号仍存在。 |

显示 → 细胞配色可切换遗传耐受／增殖／侵袭／当前非自身呈递；外轮廓颜色始终表示抗原身份。热图和 Act 可能覆盖胞体色，配方默认关闭这些覆盖层。统计 → 肿瘤性状与局部环境可比较实际高低压力群，桑基图仍展示抗原分支，不等同于全部性状克隆。

所有轨迹由局部机制生成，不保证固定环形分布或每个种子都出现大肿瘤。关闭一个机制会改变接触、分裂机会和随机流，不能把单种子的最终数量差异直接解释为机制的平均因果效应。[多种子数据与文献边界](../../reports/spatial-evolution-2026-11-13/README.md)。
