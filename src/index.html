      模型与来源

      Cell-Arena 基于 Artistoo（Wortel 与 Textor，eLife，2021） 构建。Artistoo 是在浏览器中模拟细胞与组织的开源 JavaScript 库；本网页使用其细胞 Potts 模型（CPM）实现胞体形变与相互作用，并沿用 Act 活性着色。可视化参考其 Cancer Invasion 示例。Artistoo 使用 MIT 许可，代码来源和完整许可保留在下方。

      本网页的主要扩展

      • 微环境与通讯：局部氧、糖、酸负荷，以及凝聚、损伤和免疫招募信号共同影响细胞运动、生长与存活。
      • 免疫监视：分散巡逻、局部趋化、抗原接触识别、累积杀伤、识别后招募、有限克隆扩增与可调杀伤寿命。
      • 特异识别：单个短 ATCG 抗原槽位、可遗传的识别码与交叉识别；分开遗传缺失、可逆表达、呈递能力和免疫刹车。后台有限候选谱经过抗原暴露与延迟启动，经血管增援。
      • 肿瘤演化：正常 → 癌前细胞 → 肿瘤；增殖、侵袭、耐受和抗原表达可遗传、突变，并区分不同死亡过程。
      • 干性与修复：肿瘤干细胞的对称／不对称分裂、分化与环境可塑性；有限代正常组织修复，肿瘤性状具有资源代价。
      • 细胞周期：分阶段营养需求、有限能量／合成储备与复制损伤检查点。G0 静息与 G1／S／G2／M 推进；营养、压缩和损伤控制周期。CTL 使用独立 IL-2 与抗原刺激记忆扩增，慢性刺激可累积耗竭。
      • 血管与灌注：空心内皮环、局部氧糖与排酸、循环免疫补充和真实跨内皮；有限内皮修复及肿瘤入血离场。机制与原始研究（不模拟远处定植）。
      • 形态与穿行：有限切面让位、核区约束、可变形胞核，以及可选的间质样分枝与接触成网。
      免疫遗传：机制与抽象

      ATCG 是抽象特征编码，不是真实 DNA／肽序列或 HLA 预测器。可见免疫单元综合代表部分免疫过程；粉／红／蓝状态不表示真实 CTL 可以任意转变成调节性 T 细胞。交叉呈递和启动在后台抽象，不代表 CTL 自行完成树突状细胞的全部功能。两类独立表面靶标仅预留给未来 CAR 等疗法，本轮未实现疗法按钮。

      免疫选择依据 Matsushita 等，Nature 2012；交叉识别参考 Wooldridge 等，JBC 2012；后台呈递参考 Hildner 等，Science 2008。序列长度、亲和力矩阵、启动时长及参数范围均为可玩性设置，未从这些论文拟合。

      新增机制与参数的文献对照表：Nature 的肿瘤谱系追踪、胶质瘤干性及 DNA 修复研究，Cell 的干性可塑性研究。具体概率、倍率和 MCS 时长是未标定的演示设置。

      怎么使用

      1. 选择内置情境直接运行，或在「空白自建」中摆放细胞后开始；「随机」可探索不同开局。
      2. 用画布工具添加、拖动或擦除细胞，绘制障碍、释放信号；「追踪」查看选中细胞和局部环境。
      3. 「显示」调整外观；「参数」用五个快捷按钮切换分组，锁图标保留随机换局时的固定参数。手机用顶部箭头展开或返回画布。

      「统计」查看全程曲线和带序号、种子的历局结果，可按初始参数再次模拟（不重放手动操作）；顶部文件图标导出／导入参数、保存画面或导出历局 CSV，录制图标开始／停止视频。导入参数会重新开局，不恢复中途状态。

      「肿瘤细胞／免疫细胞 → 细胞周期」调整周期参数；「追踪」查看阶段及阻滞原因。双击「信号」可添加持续 IL-2 场源，并在「显示 → 观察图层」查看其分布。

      「追踪 → 选中」查看抗原序列、当前表达／呈递与识别限制；「统计 → 抗原与克隆演化」查看主要克隆占比及实际接触覆盖。同一抗原序列与通道使用同色外轮廓；免疫胞体外轮廓以分段颜色显示同一受体能匹配的抗原，仍需呈递、启动与实际接触才能激活。旧实验保留种子及兼容参数后迁移到新规则，演化轨迹会改变。

      这是未经实验标定的二维切面演示，MCS 为模拟步数，不等同于真实时间或完整三维肿瘤。详细模型与机制参考 · 形态模型
