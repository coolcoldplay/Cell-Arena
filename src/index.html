      模型与来源

      Cell-Arena 基于 Artistoo（Wortel 与 Textor，eLife，2021） 构建。Artistoo 是在浏览器中模拟细胞与组织的开源 JavaScript 库；本网页使用其细胞 Potts 模型（CPM）实现胞体形变与相互作用，并沿用 Act 活性着色。可视化参考其 Cancer Invasion 示例。Artistoo 使用 MIT 许可，代码来源和完整许可保留在下方。

      本网页的主要扩展

      • 微环境与通讯：局部氧、糖、酸负荷，以及凝聚、损伤和免疫招募信号共同影响细胞运动、生长与存活。
      • 免疫监视：分散巡逻、局部趋化、抗原接触识别、累积杀伤、识别后招募与有限克隆扩增。
      • 肿瘤演化：正常 → 异常中间态 → 肿瘤；增殖、侵袭、耐受和抗原表达可遗传、突变，并区分不同死亡过程。
      • 细胞周期：G0 静息与 G1／S／G2／M 推进；营养、压缩和损伤控制周期。CTL 使用独立 IL-2 与抗原刺激记忆扩增，慢性刺激可累积耗竭。
      • 形态与穿行：有限切面让位、核区约束、可变形胞核，以及可选的间质样分枝与接触成网。

      怎么使用

      1. 选择内置情境直接运行，或在「空白自建」中摆放细胞后开始；「随机生成」可探索不同开局。
      2. 用画布工具添加、拖动或擦除细胞，绘制障碍、释放信号；「观察细胞」查看选中细胞和局部环境。
      3. 按六个参数分组调整细胞和环境。手机点「参数」展开面板，可直接输入数值或用 ＋／− 微调，点「返回画布」继续观察。

      「统计」查看全程数量变化；面板底部可导出／导入实验参数、保存画面和录制视频。导入参数会重新开局，不恢复中途状态。

      「肿瘤细胞／免疫细胞 → 细胞周期」调整周期参数；「观察细胞」查看阶段及阻滞原因。「持续场源」可添加 IL-2，并在「显示调整 → 观察图层」查看其分布。

      这是未经实验标定的二维切面演示，MCS 为模拟步数，不等同于真实时间或完整三维肿瘤。详细模型与机制参考 · 形态模型
