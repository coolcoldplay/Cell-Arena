观察亚群时，可在“显示 → 细胞配色”切换遗传耐受／增殖／侵袭／当前抗原呈递，抗原外轮廓保持不变；在“统计 → 肿瘤性状与局部环境”比较环境压力分组。这里展示自然产生的差异，不规定哪类必须位于核心或边缘。[三个固定种子配方与对照](experiments/spatial-evolution/README.md)。选择情境，拖动或新增细胞、释放趋化信号、绘制障碍，观察局部规则产生的群体行为。无需登录或安装，计算在访问者的浏览器内完成。

右上角点击 **Chi / Eng** 文字切换中英文，语言选择保存在当前浏览器，不重置模拟。Click Chi / Eng in the top bar to switch languages. All simulation work stays in your browser.

- **随形态变化的胞体渐变**：「显示 → 细胞配色 → 边缘淡化」按当前真实胞体轮廓生成由内向外的透明度变化，默认 80%；拉至 **0% 完全恢复原来的纯色胞体**。胞核、Act、抗原轮廓和周期文字独立显示。设置在本机记忆并随参数导出／导入，只改变外观，不改变形变、接触或生物学计算。
- **自动随机换局**：「显示」中的「自动换局」默认勾选，等待时间默认 **1 分钟**，支持小数；取消勾选即可关闭，并记住此选择。旧版未设置的 0 分钟默认迁移为开启 1 分钟；导入文件中明确写入 0 仍表示关闭。数量与离散生物状态持续不变达到等待时长，或者全部细胞消失、仅剩肿瘤、免疫为 0、正常为 0 时，先显示原因及 **10 秒倒计时**，之后随机开新局。倒计时可取消，条件恢复后自动撤销；暂停和后台不计时。迷宫情境不检查正常细胞数。

- **免疫杀伤寿命**：「参数 → 免疫 → 免疫寿命：杀伤上限」默认 10 颗，0 不限。实际递送致死损伤的免疫细胞获得一次肿瘤杀伤计数，达到上限后皱缩清除，独立计为寿命凋亡；共同接触不重复记账，杀伤癌前细胞不占用该肿瘤计数。此为可调的模拟代理，不是实验标定的真实寿命。
- **参数锁**：点击控件旁锁图标可锁定／解锁，支持全部锁定／解锁。手动「随机」和自动换局仅随机化未锁定参数；锁定不妨碍手动调值。边界、区域和精细度默认锁定，避免自动改变计算负荷；解锁后也参与有界抽样。锁全部参数仍会生成新种子。锁状态本机记忆，并随实验参数导出／导入。
- **历局结果与 CSV**：「统计 → 历局结果」直接显示局号、开始日期与时间（浏览器本地时间，精确到分钟）、结束原因、终局数量和 MCS，展开看免疫状态、肿瘤抗原组成与参数。点击「清理」后可跨页勾选、「清除所选」或「仅保留所选」（清除其他记录），也可全选所有页；确认框显示实际删除局数。清理同步删除 IndexedDB 与页面内存中的对应摘要，保留当前运行局、参数偏好及剩余记录的原局号。记录只包含摘要／参数，不保存逐帧画面或视频。CSV 包含所有已记录局与当前进行中的一局：初始／最终全部模型参数、参数调整轨迹、种子／区域／边界、MCS 与实际运行秒数、终局状态／周期、事件计数、场源及终止原因。记录保存在本机 IndexedDB；刷新本标签会恢复上次保存点并记为中断（最多约 5 秒的检查点间隔），不是可续跑的完整胞体快照。

- **设备自适应**：「其他 → 性能与计算」可选自动平衡、省电、流畅优先、高清优先。启动后测量实际绘图、数据打包、模拟步耗时及交互延迟；持续超载才逐档调整自动显示分辨率和刷新频率，稳定后逐步恢复。手机高 DPI 画布有像素预算，展开调参面板时降低小窗预览刷新；折叠且不可见的图表不再持续重绘。手动分辨率和录像质量优先于自动画质。物理格点、形变穿行、接触、微环境和细胞周期仍完整计算；计算受限时显示实际 MCS/s，不能保证任何设备都达到目标倍率。模式仅保存在本机浏览器，测量结果不上传。
- **正常细胞供给联动**：「微环境 → 正常细胞供给联动」按健康正常细胞的保留比例，同时调整全局氧、糖补给和酸清除。0% 关闭；100% 完全按比例变化。基准为本局健康正常细胞存活数的历史峰值，不因肿瘤数量增加而直接下降。比如正常细胞剩一半、联动 50%，保留 75% 的基础供给／清除能力。空白自建默认 0%，用户调节或导入明确参数后才启用；发生发展／冷／热情境分别默认 20%／20%／15%，随机情境 10–25%。这是可调的组织支持代理，与局部血管交换共同作用，不等同于全身恶病质模型。
- **全程曲线筛选与状态组成**：历史图例的四个复选框控制正常、癌前、肿瘤和免疫曲线，Y 轴仅按勾选类型缩放。只查看一类（或所选历史中仅出现一类）时自动显示状态堆叠，可勾「百分比」切换为 0–100%。免疫显示抑制／激活／静息，肿瘤和癌前显示当前非自身呈递高／低（不等于受体匹配），正常显示存活；死亡动画中的胞体单独列为「清除中」，各状态合计等于对应总数。悬停、触摸或方向键查看采样时刻的数量及占比。时间轴始终从 0 到当前；长记录显示压缩保留各状态峰谷，导出包含全部采样。
- **胞核与细小孔隙**：肿瘤胞核显示半径放大至原来的 1.38 倍；G2 随阶段进度再增大，M 期最多增加 12%。显示轮廓随胞体形变，扩大部分检查自身占据空间，狭窄处会收敛。此为显示代理，未扩大不可穿透的机械核区。修复交错单格孔隙使局部厚度检查锁住边缘的情况；只允许同一细胞四面包围的空孔按原有能量规则填补，保留胞核、胞体连通性和实体墙限制。

- **三个独立标记**：「显示 → 细胞与热图」分别开关胞核、抗原轮廓和周期文字，可同时显示。首次打开默认开启胞核；所有情境默认开启抗原轮廓，均可手动关闭。关闭胞核只隐藏胞核轮廓；肿瘤／癌前外轮廓按非自身抗原序列和通道着色，深浅表示当前呈递；免疫外轮廓分段显示原始与已学识别模板可匹配的抗原，周期以 G0／G1／S／G2／M 标出。选中细胞有跟随形变和移动的四角框。设置随参数文件保存，兼容旧显示选项。
- **细胞周期与 IL-2**：肿瘤有可逆 G0 静息及资源、压缩和损伤检查点。CTL 由真实抗原接触积累刺激记忆，配合独立 IL-2 信号、营养和有限谱系余量扩增；离开靶细胞后仍可完成支持允许的周期。慢性刺激可累积耗竭。IL-2 有独立图层与持续场源，不作为趋化信号。选中细胞可查看阶段、停滞原因和记忆／耗竭，统计页显示各阶段数量。模型时间未标定为小时。

- **实时统计展开**：「统计 → 占满侧栏」让计数、细胞周期、死亡原因、巡逻、演化事件和全程数量曲线占用整列空间，继续实时更新。保留暂停／继续、录像与返回控制按钮。短屏幕仍可独立滚动；死亡明细和统计口径可按需展开，不压缩文字到无法阅读。

- **统一开局显示**：发生发展、冷肿瘤、热肿瘤、随机生成统一使用循环边界和 3× 播放，开启胞核、抗原轮廓、周期文字、环境恶劣度和免疫招募图层，关闭运动轨迹及 Act。保留区域大小与精细度。普通「重来」保留用户已调整的显示、边界和速度；重新选择情境恢复默认。
- **随机生成**：生成密铺正常组织、12–16 颗分散免疫细胞、三处弱供给区域，初始零肿瘤／癌前；在发生发展参数附近随机抽样，使局部癌前、癌变、清除、抑制和恢复有机会竞争。采用上述统一显示设置，种子随导出保存；「重来」复现该配置。随机范围用于探索模型，不是实验测得的生物学正常范围。
- **释放信号**：合并瞬时释放和持续场源，单击释放一次，长按连续释放（可拖动），松手停止；双击建立固定场源。类别包括各类因子、独立的氧气、葡萄糖、酸负荷，以及氧糖补给和乏氧高酸组合。区域半径可调，「擦除场源」删除固定源；触摸操作相同。单击等待约 320 ms 区分双击，双击不会同时额外释放两个脉冲。该工具激活时隐藏悬停信息和原生标题；切回观察即可查看浓度。
- **工具配对**：拖动／观察细胞、新增／擦除细胞、绘制／擦除障碍分别上下对应；信号按钮与其余按钮同尺寸。移除平移工具按钮，仍可用中键或 Alt＋左键平移放大的画布。
- **批量新增**：「新增细胞」中，细胞类型、数量和「＋ 加入」放在同一行，数量默认为 5，可改为任意有效正整数。按钮在空隙中随机放置该类型细胞，并反馈实际加入数；空间不足时可能只加入一部分。画布单击仍只加入一颗。

- **铺满的正常单层**：三个肿瘤情境都采用覆盖全部区域的连续多边形组织。发生发展无预植肿瘤，12 颗免疫细胞散布内部；冷／热情境将中央 19／37 个组织区域初始化为肿瘤，外围分别嵌入 3／18 颗免疫细胞，不留空白隔离带。密铺的视觉布局参考 Artistoo Cancer Invasion，初始化采用本项目的加权 Voronoi 分区。
- **Act 默认显示**：仅免疫迷宫默认开启免疫细胞 Act。切换到其他情境恢复关闭，仍可手动启用各类型的 Act；普通重来保留用户设置，恢复情境则恢复默认。
- **免疫迷宫**：顶部「免疫迷宫」默认使用至少 384×288 的区域，圆形多环迷宫、6 个等距入口、6 颗编号免疫细胞。默认约 13 环，通道净宽约 5–7 个模型长度，窄于静息免疫细胞的直径；区域更大时增加环数。圆弧与直线共用一套显示／碰撞几何，墙接头对齐、端点齐平，6 条入口路线都需要明显绕行。胞核进入中央终点区记录首次到达用时，同一 MCS 到达可并列；后续离开不删除成绩。新增细胞不参与原始六颗的竞赛。所有移动仍受实际墙体、胞核和连通性约束。
- **运动轨迹**：「显示 → 细胞与热图」开启，保留时长可调 20–2000 MCS。按收到的模拟快照记录细胞质心，不改变模型；高倍率下为采样折线。暂停不消退，重新开局清空，分裂后的子代独立记录，循环边界不画横贯画布的连线。
- **持续场源**：在「释放信号」工具下双击建立。因子源固定局部浓度为 30；独立氧／糖／酸源只将对应场维持在 1；氧糖源将两者维持在 1；乏氧高酸区域将氧设为 0.06、酸负荷设为 0.95。墙内不生效，墙阻断扩散；循环边界两侧连续，擦除后剩余场自然演化。相互冲突的固定条件按放置先后生效，最后者优先；源定义随参数导出／导入。
- **肿瘤趋营养运动**：即使尚未受到代谢压力，肿瘤也根据自身胞体附近的氧和糖梯度向浓度较高处偏转，强度随「趋化响应」调节。方向仍结合持续极性、局部细胞接触和恶劣环境逃逸；实体障碍、核区和胞体连通约束继续生效。没有读取远处营养源位置，是未标定的现象学行为。
- **子代标记**：详情中的 P0、P1、P2… 为从初始细胞起的谱系分裂次数。点选观察后，青色四角框跟随所选细胞；分裂后的两颗子细胞和更后代均继续标记，不同相对代次换色，右上角小数字 1、2、3… 从此次选中的细胞起计数。再次点选建立新观察谱系，点空白或重新开局清除。免疫剩余分裂预算另行显示。

迷宫采用持续供给／清除的扩散实验：圆心招募源维持上限，外圈入口接低浓度储库，默认实体墙为无通量边界。Arena 右下角「招募扩散」可切换沿通道／穿墙扩散，只改变招募因子；细胞和其他环境场仍受实体墙约束，位置、时间与比赛成绩保留。开局求解同一局部扩散方程的稳态，运行时继续扩散；这个情境的招募场不使用普通脉冲的半衰期，其他因子仍衰减。细胞只采样附近浓度梯度，未读取迷宫图、路线或终点坐标来导航；拖动细胞、编辑障碍或添加场源可以改变结果。

基于 [Artistoo（Wortel 与 Textor，eLife，2021）](https://doi.org/10.7554/eLife.61288) 构建，采用其开源细胞 Potts 模型库。网页「模型与来源」简要介绍 Artistoo、本网页新增模拟特点与使用方法；详细机制见 [MODEL.md](MODEL.md)。直接包含的库、改写／移植的内核、MT19937 随机数实现及其完整许可范围见 [代码来源与第三方声明](THIRD_PARTY_NOTICES.md)。

直接打开 `dist/index.html`（或兼容入口 `dist/artistoo-playground.html`）即可离线运行。官方 Artistoo、WebAssembly、GPU 着色器、模型、Worker 和页面均内嵌，模拟运行无需 npm 依赖或 CDN。

正式网站 `https://coolcoldplay.github.io/Cell-Arena/` 使用 [Cloudflare Web Analytics](https://developers.cloudflare.com/web-analytics/) 记录访问与页面性能。统计加载器位于 `src/index.html`，使用 Cloudflare 提供的公开站点标识，只在该 HTTPS 主机和项目路径下加载；本地 HTTP、离线文件和其他托管地址不加载统计脚本。统计被阻止或不可用不会阻止模拟启动，实验参数和细胞数据没有接入统计上报。

## 本版重点

- **可恢复的蓝色免疫抑制样状态**：正常细胞损伤来源的信号持续暴露，可让粉色细胞转蓝、红色细胞退激活；蓝色细胞主要趋向正常损伤高的局部区域，分泌独立抑制场，促进附近红色细胞退回粉色。当前损伤和累计暴露降低后，可随机恢复粉色。恢复速度在「免疫细胞 → 损伤应答与免疫抑制」调节，0 关闭；恢复事件单独统计。保留真实形变、运动和墙限制；蓝色不抗肿瘤杀伤。两种信号支持独立图层、透明度、悬停及手动持续场源。这是功能状态实验，非真实 CTL→Treg 转分化模型，具体边界见 [MODEL.md](MODEL.md)。
- **克隆特异性识别**：单个短序列抗原槽、当前表达、呈递通道和稳定受体分开计算；失去有效匹配后解除对应接触绑定。已有趋化场继续衰减，不携带抗原身份；实际杀伤仍须共享膜边。

- **遗传、表达与选择分开**：压力和 DNA 损伤调整分裂突变机会；局部序列／调控变化只建立对应子代分支。环境响应可以双向且可逆；接触／招募只调节可逆呈递，不定向产生遗传逃逸。不同克隆经真实识别和损伤发生选择。
- **控件位置**：正常细胞组调整正常压力致变；「肿瘤细胞 → 突变与抗原演化」调整肿瘤变异及抗原变化；「微环境 → 演化实验」调整适应偏向与选择记忆。默认偏向 0，正负偏向只是对照实验假设，见 [MODEL.md](MODEL.md)。
- **密铺死亡清除**：已死亡的非裂解胞体在 CPM 收缩受阻时继续逐步从边缘脱落，不再永久占位；不删除健康细胞，死亡计数仍以真实清除为准。

- **紧凑工作台**：米色底、像素风方形控件，arena 默认等比例铺满左侧；页面和左侧不滚动，参数区独立滚动。去掉宣传标题与常驻长说明，情境、播放和工具集中到右侧，统计与模型解释按需展开。中键或 Alt + 左键平移视野，「显示 → 视野与边界」可切回完整培养皿；视野变化不改变模拟。
- **空白自建**：三个内置情境旁新增第四个入口，从 0 MCS、无细胞／障碍／信号的暂停画布开始，自动选择新增工具。自由点击摆放正常、肿瘤和免疫细胞，也可拖动、画墙、释放信号；准备好后点击继续。自建模式的「重来」清空布置，回到暂停状态。
- **炎性信号促癌**：「微环境」中新增 0–10× 滑杆。局部损伤／招募信号按胞体占据加权并累积，增加正常 → 癌前的随机风险，仍经过至少 160 MCS、但不保证可被现有免疫克隆识别的癌前中间态。0 关闭这条独立通路；发生发展默认 1.3×，冷／热情境默认 0。为未标定的炎症代理，非特定细胞因子的临床剂量关系，公式和原始研究见 [MODEL.md](MODEL.md)。
- **可区分的死亡过程**：免疫杀伤后实际胞体圆化、有限肿胀、由原胞体色渐变为橙黄色后破裂；自发凋亡皱缩消失，环境死亡灰褐萎缩。四类原因分别记账（含免疫寿命凋亡），清除完成才增加清除数。0% 只阻止新的随机凋亡，环境／免疫致死及此前已触发的死亡仍会继续。橙黄色裂解是可视化约定，不代表所有免疫杀伤的真实死亡方式。
- **胞核适度变形**：核轮廓有个体差异，并随附近真实胞体的伸长／挤压缓慢变化与恢复。变形范围受限，保留原有核区保护，不生成细丝状胞核；颜色仍可自定义。
- **统一擦除**：可调半径的「擦除」工具移除触及的整颗细胞、持续场源及局部障碍，同时清除刷到的局部因子／酸，氧糖恢复为 1。邻近细胞和保留的场源仍可重新影响该区域。手动移除独立计数，不混入生物学死亡。
- **弹性拖动**：沿途邻居连同核区逐格侧移，受限时尝试局部变形和有界切面让位；不再碰到一个相邻像素就停下。整个手势期间暂停形变演化、代谢、信号扩散与生物事件；松手恢复原播放状态。实体墙、核区和连通性仍受保护。
- **动态间质样形态**：在「形态与穿行」选择梭形或胶质瘤样分枝。局部前缘可伸长、弯曲、分叉和回缩，数量与长度各异；真实膜接触后稳定连接，保留核区、有限宽度和实体墙约束。可一键启动分枝成网示例。研究依据与模型边界见 [MORPHOLOGY.md](MORPHOLOGY.md)，不声称已定量复现 U87MG。
- **胞体／胞核自定义颜色**：「细胞配色」分别设置六类细胞／功能状态，立即生效、浏览器记忆、一键恢复，并随实验数据导出。可选择保留肿瘤增殖深浅变化；GPU 与 Canvas 显示一致。
- **取消全局数量预算**：生长、自动／手动分裂和新增不再被 240／320／2048 等人为数量阈值截断，旧配置中的 `capacity` 被忽略。继续检查营养、累积压力、实际空间、核区和免疫谱系剩余分裂次数；性能不足只提示实际推进速度。
- **修复拥挤锁死**：新生长还检查本细胞的实际面积相对目标切面的压缩程度。拥挤时渐减、低于目标切面的 90% 时停止新增生物量，得到空间后恢复；不再让未实现的生长不断抬高硬面积下限。不会因此关闭免疫运动，也不会削减既有生物量或放宽核区／薄颈约束；分裂次数耗尽的免疫细胞仍可巡逻与杀伤。
- **三种重做情境**：肿瘤发生发展、免疫冷肿瘤扩散转移、免疫热肿瘤应答。分别配置细胞开局、环境和免疫参数，显示实际阶段、克隆扩增／远端分裂／清除进度；支持一键恢复情境设定。血管加入后的供给、清除、储备与随机参数范围已重新校准，见 [校准与多种子检查](SCENARIO_CALIBRATION.md)。
- **状态配色与默认核区**：正常灰色；免疫未激活为淡红、实际识别后激活为深红；肿瘤增殖性状越高越黑。默认显示真实力学核区，正常核轮廓用深蓝，淡红免疫用深红，深色胞体用浅金。仅迷宫情境默认开启免疫 Act；其他情境默认关闭，可按类型手动启用。
- **四大导航**：显示、参数、统计、选中；胞核、抗原／周期标记、图层与透明度、轨迹、配色及录像设置统一放在显示。参数页固定横排微环境、体细胞、肿瘤、免疫、其他五个按钮，只显示当前组。工具按拖动／追踪、新增／擦除、障碍／信号两行排列；顶部文件图标集中图片、实验 JSON 和历局 CSV 导出与参数导入，录制图标开始／停止，问号打开模型与来源。
- **快捷观察图层**：「显示 → 观察图层」一键开关环境恶劣度，以及青绿的细胞凝聚、橙色的损伤趋化、紫色的免疫招募因子。三种因子独立选择、可同时叠加，颜色越浓表示信号越强，重叠区域混色；「关闭叠加」恢复胞体视图。
- **独立透明度与悬停**：图层滑杆 0% 隐藏，50% 以下保护胞体色，高值逐渐放宽保护，100% 完整显示图层；核区和细边界最后绘制。各通道独立，环境分量分别记忆设置。因子增强低浓度显示；仅在「追踪」工具下悬停返回原始模型浓度，障碍处显示无效读数。其他工具隐藏位置小窗；追踪时鼠标静止 10 秒也自动收起，移动后恢复。
- **正常 → 癌前 → 肿瘤**：正常细胞也会环境致死。持续压力提高进入褐色癌前细胞的随机风险；癌前态表达部分抗原、保留正常运动且不能分裂，能被免疫提前清除。独立的后续转变才赋予肿瘤增殖侵袭表型；风险不是必然结果，环境损伤与后续转变的倍率在「正常细胞」中调整。
- **GPU 与 WebAssembly**：WebGL2 在 GPU 上生成画面；WebAssembly 加速保持顺序的 CPM 复制循环。可选 WebGPU 执行微环境扩散反应，自动模式实测完整传输时间择优。CPU 回退保留全部机制。
- **切面让位**：邻居受挤时逐步减少可见目标面积并在压力解除后恢复；保留总目标生物量和切面外部分的代谢贡献。默认让位上限 35%，可设 0–50%。
- **核区与细丝约束**：实际占据的核区限制过窄通道，短突起必须变宽后继续伸展；活胞体保持四邻接连通。提供核区调试叠加、可见比例与切面外储量读数。
- **密度—代谢反馈**：局部氧、糖、酸负荷持续变化，抑制增殖与免疫效能、累积环境损伤，并影响局部逃逸方向。
- **免疫招募与克隆扩增**：真实接触识别后分泌招募因子；免疫分裂有谱系预算，肿瘤没有固有代数上限。
- **免疫分散巡逻**：免疫的前端伸展与后端收缩共同受极性驱动；拥挤时适度降低软性轮廓张力，胞核、连通性和最细颈部限制保留。墙接触也计入机械约束，使窄道中的轮廓能适度变形。免疫之间采用弱贴靠／独立分离，不无条件跟随同类；有损伤或招募梯度时才定向趋化。「免疫细胞 → 免疫同类分离」可单独调整，扫描／杀伤靶细胞时不施加这项分离。仅被吸引的细胞和未自行识别的新免疫子细胞不自动释放招募信号。细胞详情显示「分散巡逻」「局部趋化」「接触扫描」或「识别后递送损伤」。
- **遗传与突变**：肿瘤耐受、增殖、侵袭和抗原表达随分裂遗传／变异；选择细胞可查看性状、代数和克隆编号。
- **可调空间与高清显示**：培养区域最高 512×384，格点精细度最高 4×，有效组合最高 1024×768 真实格点。独立显示分辨率可选自动、1920×1440、2560×1920、3840×2880；自动适配缩放／全屏／屏幕密度，保存 PNG 使用同样尺寸。
- **单击挤入**：已有细胞处也可加入一颗细胞；局部变形、连续核区让位及有界切面压缩均在草稿中计算，验证后整体提交。失败不改动组织，墙和核区仍受保护，不再按全局细胞数拒绝加入。

## 操作

| 工具／视图 | 用法 |
|---|---|
| 拖动细胞 | 按住移动真实轮廓，沿途邻居侧移或弹性让位；全过程暂停，松手恢复原播放状态。墙与无法容纳核区的空间仍阻挡。 |
| 新增细胞 | 选择类型，单击加入一颗；有细胞处尝试局部挤入。按钮在空隙中随机加入 5 颗。 |
| 释放信号 | 选择凝聚、损伤趋化或免疫招募因子；点击／拖动释放，同时打开对应观察图层，保留其他已选图层。不会直接触发杀伤。 |
| 擦除细胞 | 调节半径后按住拖动，删除触及的整颗细胞。手动移除独立记账；已触发的死亡被手动中止时不会伪计为自然清除。 |
| 平移视野 | 使用工具拖动画面，或随时按中键／Alt + 左键；不移动细胞，不改变模型。 |
| 绘制／擦除障碍 | 在空地拖动画墙，或擦出通路。墙不覆盖已有细胞。 |
| 观察细胞 | 查看代谢状态、累积压力、抗原、损伤、性状、克隆和剩余分裂次数。 |
| 环境叠加 | 「显示 → 观察图层」点击「环境恶劣度」查看低氧、低糖与高酸的综合指标：浅绿友好，黄至暗红越来越恶劣，范围 0–1。图例紧邻开关。 |
| 环境分量 | 「显示 → 细胞与热图」选择氧、糖、酸负荷或局部密度。环境热图与三种因子可同时显示。 |
| 视野与边界 | 「显示 → 视野与边界」中调整；区域大小与格点精细度需点「应用」重新开始。默认铺满左侧，保持细胞比例，超出视口部分可中键或 Alt + 左键平移查看，也可选择完整培养皿。 |
| 空白自建 | 点击第四个情境入口，选细胞类型后逐颗点击摆放；设置期间暂停，点击继续才开始演化。「重来」清空当前布置。 |

**三个内置情境**（默认 240×180 区域、1.5× 精细度；发生发展每次访问生成新种子，冷／热保持种子 17）：

| 情境 | 初始细胞与关键设置 | 观察过程 |

培养液 `#F6F0E2`，正常 `#CCCCCC`，癌前 `#A08B66`；未激活免疫 `#E99A9A`，激活免疫 `#990000`，抑制样免疫 `#6398D2`。深红读取识别后的激活记忆，克隆子代继承剩余激活期，到期或退激活后恢复淡红；单纯趋化和未完成识别的扫描不会变色。肿瘤的遗传增殖性状 0.25–3 固定映射到灰度 88–0，即深灰到纯黑；实际生长还受全局参数、营养和压力影响，点击细胞可看性状值。强热图或 Act 会覆盖这些胞体色，调低图层强度即可恢复。

环境恶劣度表示当前位置的即时资源状态，不是细胞累计损伤；损伤趋化因子是独立浓度场。可选红色膜轮廓深浅表示当前非自身呈递强度，不保证与某个免疫克隆匹配。Act 是骨架前沿代理，不是实测骨架浓度。细胞运动依靠局部梯度和接触，无全局最近目标追踪。

初始抗原比例、免疫初始分裂次数只影响新播种的细胞。已有肿瘤的抗原槽位由遗传决定，当前表达与呈递还受可逆局部调控，已有免疫细胞的剩余次数不会被滑块重置。正常背景按几何间距铺设，大区域不再按数量预算抽稀；为肿瘤团和免疫细胞预留真实空间。「性能与计算」显示细胞数、格点和后端信息，不设控制细胞生长的全局数量滑杆；1000 颗以上的负载提示仅用于提醒，不改变动力学。

1× 目标 30 MCS/秒，支持 0.25–8×；固定步长，算力不足时显示实际速率和提示。区域、精细度、边界改变会重新开始；「重来」保留参数与种子，「随机生成」生成新的参数与细胞布局。点击情境或「恢复情境设定」恢复该情境参数、初始细胞、建议图层与播放倍率：发生发展使用本次页面访问的开局种子，其余预设使用 17；保留区域／精细度。空格暂停／继续。

发生发展的访问种子使用毫秒时间、高精度启动计时和浏览器随机数混合为完整的 32 位整数。同一毫秒进入的访客也有独立随机输入；不采集身份信息，不在模拟运行中重新播种。种子的数值距离不代表演化距离，因此观赏性的范围由固定的发生发展参数、三处弱供给区域、健康边缘与初始免疫配置维持，不采用筛选预定胜负的种子名单。新的访问改变随机轨迹，不能保证每局都发生全部状态或全局绝不重复。实际种子显示并随实验参数导出；在同版本、参数、边界、后端和操作下可复现。导入文件的种子始终优先；「重来」复现当前实验，刷新网页获得新访问开局。

POPULATION HISTORY 显示本次模拟从 0 MCS 到当前查看时刻的完整时间范围，不再删除早期数量记录。每 30 MCS 采样，手动新增／分裂即时记入，当前数量补齐到曲线右端；暂停时横轴停止，重新开始时清空旧历史。长记录只在绘图时按时间区间保留各类细胞的峰谷，原始采样仍完整保存。

「细胞配色」提供岩灰·珊瑚（推荐）、瓷白·朱砂、雾青·胭脂、雾紫·玫瑰四套方案。点击即刻切换五种状态的胞体／胞核，仍可逐项自定义并保存在本浏览器；不会重置模型或改变生物学。原始配色可一键恢复。

“死亡清除”在胞体实际消失时记账，分别显示免疫杀伤、环境死亡、自发凋亡、寿命凋亡。主统计中的当前存活数不含清除中的胞体，历史曲线保留该类清除状态。展开“死亡明细”可查看各原因清除中／已触发数、最近清除和触发记录，以及单独的手动移除数。完整死亡档案包含稳定出生编号、原因与触发／清除时刻。

导出 PNG 或 JSON。JSON 包含配置、情境初态与实际进度、空间补给／清除系数图、细胞表型、从开局到当前的完整数量采样历史及 `deathHistory` 死亡记录、最近交互事件和有限长度谱系记录，**不是完整可恢复的状态检查点**。

## 加速路径与构建

此前 v4 加速验收（透明度／癌前监视更新前）在本机 RTX 4050 / Chrome 实测：640×480、144 颗细胞的纯模型循环，WASM 约 86 MCS/秒，相同 v4 JS 规则约 18.4；最大 768×576、208 颗细胞约 45.6。浏览器含显示实测：288×216 的 0.5×、2×、4×约 15、60、119 MCS/秒；640×480 从 1×约 30 提升至高倍率约 58 MCS/秒。数值随场景和系统负载变化，达到算力上限后不能保证倍率线性增长。

微环境当前使用较粗网格，CPU 常比 GPU 的传输／读回更快，自动模式会如实显示测速结果。GPU 绘图与微环境后端独立；WASM 是 CPU 加速，不是 GPU 形变。所有形变、接触和代谢步仍执行。

普通 `npm run build` 使用随源代码保留的 `build/cpm-kernel.wasm`，并核对 C 源码与二进制哈希。修改 C 后需 `npm run build:wasm`：使用 [官方 WASI SDK](https://github.com/WebAssembly/wasi-sdk) 的 Clang，设置 `WASI_CLANG` 指向可执行文件（或放在 `.tooling/wasi-sdk-20.0+m/bin/clang.exe`）。本次使用 SDK 20 / Clang 16，编译参数记录于 `build/cpm-kernel.meta.json`；浏览器运行不需要编译器。

## 大画布性能与复测

内部格点的邻接关系在 WASM 中直接计算，仅边界保留查表；成功复制按原顺序维护体积、Act、占据和巡逻，已由 WASM 算完的周长／边界直接导入，避免 JS 重算。额外像素监听器自动使用完整回放。完整保留形变、核区、真实接触、微环境与细胞周期。高分辨率快照采用分块转置，WASM 额外加速栅格打包；JS 回退提供相同结果。绘图复用 GPU 纹理，抗原细线直接在 GPU 中沿膜边绘制。

Arena 最多每秒推送 60 张新状态，自动帧最多两张在途；绝对截止时刻保持发布节奏，避免慢模型步与打包时间叠加后意外丢失一半帧率。渲染忙时合并显示更新，模拟继续计算。侧栏和全程曲线按性能模式以最多 4–8 Hz 更新，交互过载时进一步放缓，用户操作立即刷新；不可见的图表不持续重绘。胞核按颜色分批，每条路径最多 32 个轮廓，避免 Chromium 大路径构建成本；形变、颜色和周期边界副本不变。渐变距离场使用独立、只读的 WASM 内核，透明度逐字节匹配 JS，加载失败保留 JS 回退。它不更改物理格点或随机数，48 MiB 线性内存与 128 MiB 形变内存分离。完整历史与实验导出不降采样。

「其他 → 性能与计算」新增实际画面更新 FPS、绘制与打包耗时。FPS 只计展示过的新模型时刻，不计重复重绘；1× 仍是 30 MCS/秒，高倍率受实际计算能力限制，最大格点密铺不能保证 60 FPS。不会自动降低物理分辨率或冻结增殖。
