# Cell-Arena · 细胞生态竞技场

[在线体验](https://coolcoldplay.github.io/Cell-Arena/) · [GitHub 源码](https://github.com/coolcoldplay/Cell-Arena)

在浏览器里探索细胞形变、肿瘤进化、免疫接触杀伤与微环境。选择情境，拖动或新增细胞、释放趋化信号、绘制障碍，观察局部规则产生的群体行为。无需登录或安装，计算在访问者的浏览器内完成。

基于 [Artistoo](https://github.com/ingewortel/artistoo)（Johannes Textor、Inge Wortel）构建。直接包含的库、改写／移植的内核、MT19937 随机数实现及其完整许可范围见 [代码来源与第三方声明](THIRD_PARTY_NOTICES.md)。

直接打开 `dist/index.html`（或兼容入口 `dist/artistoo-playground.html`）即可离线运行。官方 Artistoo、WebAssembly、GPU 着色器、模型、Worker 和页面均内嵌，无 npm 依赖或 CDN。

本地开发使用 Node.js 24 或更高版本，无需 `npm install`：

```powershell
npm run build
npm run dev
```

然后访问 [本地实验室](http://127.0.0.1:4175/)。服务器每次读取当前构建文件。本仓库发布当前的二维 CPM 切面模拟器；早期独立的 2.5D 原型不包含在此仓库。

## 网页部署

`.github/workflows/pages.yml` 在推送 `main` 后运行模型测试、构建并核对单文件，再自动部署到 GitHub Pages。拉取请求只执行测试和构建，不发布。仓库 Pages 的构建来源为 **GitHub Actions**。

```sh
npm test
npm run build
npm run verify:build
```

静态托管目录为 `dist/`，入口为 `index.html`；没有后端、数据库或 API 密钥。也可以把 `dist/` 放到其他 HTTPS 静态服务。现代桌面 Chrome／Edge 体验较佳；WebGPU 不可用时微环境计算会回退到 CPU。高分辨率、多细胞运行的实际速率取决于访问者设备。

开发生成的 `output/` 测试证据、浏览器配置和编译工具缓存不上传仓库；历史验收记录中的这些路径指本地输出，可用对应脚本重新生成。

## 本版重点

- **动态间质样形态**：在「形态与穿行」选择梭形或胶质瘤样分枝。局部前缘可伸长、弯曲、分叉和回缩，数量与长度各异；真实膜接触后稳定连接，保留核区、有限宽度和实体墙约束。可一键启动分枝成网示例。研究依据与模型边界见 [MORPHOLOGY.md](MORPHOLOGY.md)，不声称已定量复现 U87MG。
- **胞体／胞核自定义颜色**：「细胞配色」分别设置五类细胞／激活状态，立即生效、浏览器记忆、一键恢复，并随实验数据导出。可选择保留肿瘤增殖深浅变化；GPU 与 Canvas 显示一致。
- **取消全局数量预算**：生长、自动／手动分裂和新增不再被 240／320／2048 等人为数量阈值截断，旧配置中的 `capacity` 被忽略。继续检查营养、累积压力、实际空间、核区和免疫谱系剩余分裂次数；性能不足只提示实际推进速度。
- **修复拥挤锁死**：新生长还检查本细胞的实际面积相对目标切面的压缩程度。拥挤时渐减、低于目标切面的 90% 时停止新增生物量，得到空间后恢复；不再让未实现的生长不断抬高硬面积下限。不会因此关闭免疫运动，也不会削减既有生物量或放宽核区／薄颈约束；分裂次数耗尽的免疫细胞仍可巡逻与杀伤。
- **三种重做情境**：肿瘤发生发展、免疫冷肿瘤扩散转移、免疫热肿瘤治愈。分别配置细胞开局、环境和免疫参数，显示实际阶段、克隆扩增／远端分裂／清除进度；支持一键恢复情境设定。
- **状态配色与默认核区**：正常灰色；免疫未激活为淡红、实际识别后激活为深红；肿瘤增殖性状越高越黑。默认显示真实力学核区，正常核轮廓用深蓝，淡红免疫用深红，深色胞体用浅金。Act 可按类型分别开关。
- **背景与参数导航**：培养液改为浅灰白，与灰色正常细胞区分。右侧十个参数模块默认折叠，点击展开，展开另一组时收起前一组；提供「全部收起」。
- **快捷观察图层**：画布上方一键开关环境恶劣度，以及青绿的细胞凝聚、橙色的损伤趋化、紫色的免疫招募因子。三种因子独立选择、可同时叠加，颜色越浓表示信号越强，重叠区域混色；「关闭叠加」恢复胞体视图。
- **独立透明度与悬停**：图层滑杆 0% 隐藏，50% 以下保护胞体色，高值逐渐放宽保护，100% 完整显示图层；核区和细边界最后绘制。各通道独立，环境分量分别记忆设置。因子增强低浓度显示，悬停仍返回原始模型浓度，障碍处显示无效读数。
- **正常 → 异常 → 肿瘤**：正常细胞也会环境致死。持续压力提高进入褐色异常中间态的随机风险；异常态表达部分抗原、保留正常运动且不能分裂，能被免疫提前清除。独立的后续转变才赋予肿瘤增殖侵袭表型；风险不是必然结果，倍率在「微环境与生存」中调整。
- **GPU 与 WebAssembly**：WebGL2 在 GPU 上生成画面；WebAssembly 加速保持顺序的 CPM 复制循环。可选 WebGPU 执行微环境扩散反应，自动模式实测完整传输时间择优。CPU 回退保留全部机制。
- **切面让位**：邻居受挤时逐步减少可见目标面积并在压力解除后恢复；保留总目标生物量和切面外部分的代谢贡献。默认让位上限 35%，可设 0–50%。
- **核区与细丝约束**：实际占据的核区限制过窄通道，短突起必须变宽后继续伸展；活胞体保持四邻接连通。提供核区调试叠加、可见比例与切面外储量读数。
- **密度—代谢反馈**：局部氧、糖、酸负荷持续变化，抑制增殖与免疫效能、累积环境损伤，并影响局部逃逸方向。
- **免疫招募与克隆扩增**：真实接触识别后分泌招募因子；免疫分裂有谱系预算，肿瘤没有固有代数上限。
- **免疫分散巡逻**：免疫之间采用弱贴靠／独立分离，不无条件跟随同类；有损伤或招募梯度时才定向趋化。「局部通讯与趋化 → 免疫同类分离」可单独调整，扫描／杀伤靶细胞时不施加这项分离。仅被吸引的细胞和未自行识别的新免疫子细胞不自动释放招募信号。细胞详情显示「分散巡逻」「局部趋化」「接触扫描」或「识别后递送损伤」。
- **遗传与突变**：肿瘤耐受、增殖、侵袭和抗原表达随分裂遗传／变异；选择细胞可查看性状、代数和克隆编号。
- **可调空间与高清显示**：培养区域最高 512×384，格点精细度最高 4×，有效组合最高 1024×768 真实格点。独立显示分辨率可选自动、1920×1440、2560×1920、3840×2880；自动适配缩放／全屏／屏幕密度，保存 PNG 使用同样尺寸。
- **单击挤入**：已有细胞处也可加入一颗细胞；局部变形、连续核区让位及有界切面压缩均在草稿中计算，验证后整体提交。失败不改动组织，墙和核区仍受保护，不再按全局细胞数拒绝加入。

## 操作

| 工具／视图 | 用法 |
|---|---|
| 拖动细胞 | 按住细胞移动真实轮廓；遇到实体占据停止，拖动期间暂停，松手恢复。 |
| 新增细胞 | 选择类型，单击加入一颗；有细胞处尝试局部挤入。按钮在空隙中随机加入 5 颗。 |
| 释放信号 | 选择凝聚、损伤趋化或免疫招募因子；点击／拖动释放，同时打开对应观察图层，保留其他已选图层。不会直接触发杀伤。 |
| 绘制／擦除障碍 | 在空地拖动画墙，或擦出通路。墙不覆盖已有细胞。 |
| 观察细胞 | 查看代谢状态、累积压力、抗原、损伤、性状、克隆和剩余分裂次数。 |
| 环境叠加 | 画布上方点击「环境恶劣度」查看低氧、低糖与高酸的综合指标：浅绿友好，黄至暗红越来越恶劣，范围 0–1。图例紧邻开关。 |
| 环境分量 | 展开「细胞与热图显示」，选择氧、糖、酸负荷或局部密度。环境热图与三种因子可同时显示。 |
| 视野与边界 | 展开对应模块；区域大小与格点精细度需点「应用」重新开始，放大查看不改计算。 |

**三个内置情境**（默认 240×180 区域、1.5× 精细度、种子 17）：

| 情境 | 初始细胞与关键设置 | 观察过程 |
|---|---|---|
| 肿瘤发生发展 | 48 正常＋4 免疫，零异常／肿瘤。中心酸清除受限、氧糖补给略低，外围供给较好；两阶段风险倍率均为 8，肿瘤生长 1.2，新生肿瘤的初始遗传耐受为 2.04–2.76。默认 4× 播放。 | 真实代谢压力 → 异常中间态 → 随机恶性转变 → 存活克隆扩增；没有预置癌细胞或定时强制事件。 |
| 免疫冷肿瘤扩散转移 | 52 正常＋中心 19 肿瘤＋3 外围免疫；新肿瘤抗原阳性概率 15%，生长 1.4、运动 1.15、招募 0.35。 | 原灶外播散及远端分裂；统计只跟踪最初 19 颗肿瘤的后代。这里是二维扩散代理，不包含血管／跨器官转移。 |
| 免疫热肿瘤治愈 | 35 正常＋中心 37 肿瘤团＋周边 18 免疫；抗原 100%，肿瘤生长 0.75，杀伤 2、招募 2.4、有限免疫增殖 0.65。 | 肿瘤仍可分裂；实际接触识别 → 招募与克隆扩增 → 清除创始肿瘤及其后代；全部胞体消失并继续观察 150 MCS 后提示当前区域持续清除。 |

这些是有意拉开动力学差异的演示情境，不是只改变免疫数量的严格对照实验。冷、热情境关闭新的环境诱发异常，以观察已有病灶的结局；形变、真实接触、代谢抑制和有限免疫分裂仍启用。旧场景作为内部回归夹具保留，不再显示为首页入口。三个固定种子的结果见 [CHECK_RESULTS.md](CHECK_RESULTS.md)，改变种子、区域、精细度或手动操作不保证同样结局。

培养液 `#F3F5F1`，正常 `#CCCCCC`，异常 `#A08B66`；未激活免疫 `#E99A9A`，激活免疫 `#990000`。深红读取识别后的激活记忆，克隆子代继承剩余激活期，到期恢复淡红；单纯趋化和未完成识别的扫描不会变色。肿瘤的遗传增殖性状 0.25–3 固定映射到灰度 88–0，即深灰到纯黑；实际生长还受全局参数、营养和压力影响，点击细胞可看性状值。强热图或 Act 会覆盖这些胞体色，调低图层强度即可恢复。

环境恶劣度表示当前位置的即时资源状态，不是细胞累计损伤；损伤趋化因子是独立浓度场。`＋` 是可选抗原标记。Act 是骨架前沿代理，不是实测骨架浓度。细胞运动依靠局部梯度和接触，无全局最近目标追踪。

初始抗原比例、免疫初始分裂次数只影响新播种的细胞。已有肿瘤的抗原由遗传决定，已有免疫细胞的剩余次数不会被滑块重置。正常背景按几何间距铺设，大区域不再按数量预算抽稀；为肿瘤团和免疫细胞预留真实空间。「性能与计算」显示细胞数、格点和后端信息，不设控制细胞生长的全局数量滑杆；1000 颗以上的负载提示仅用于提醒，不改变动力学。

1× 目标 30 MCS/秒，支持 0.25–8×；固定步长，算力不足时显示实际速率和提示。区域、精细度、边界改变会重新开始；「重来」保留参数与种子，「换个开局」换种子。点击情境或「恢复情境设定」恢复该情境参数、种子 17、初始细胞、建议图层与播放倍率，保留区域／精细度／边界选择。空格暂停／继续，单步推进 1 MCS。

POPULATION HISTORY 显示本次模拟从 0 MCS 到当前查看时刻的完整时间范围，不再删除早期数量记录。每 30 MCS 采样，手动新增／分裂即时记入，当前数量补齐到曲线右端；暂停时横轴停止，重新开始时清空旧历史。长记录只在绘图时按时间区间保留各类细胞的峰谷，原始采样仍完整保存。

导出 PNG 或 JSON。JSON 包含配置、情境初态与实际进度、空间补给／清除系数图、细胞表型、从开局到当前的完整数量采样历史、最近事件和有限长度谱系记录，**不是完整可恢复的状态检查点**。

- `tests/model.test.mjs`：原有接触／杀伤／边界／扩散／拖动等回归。
- `tests/unrestricted-growth.test.mjs`：旧数量参数不影响生长／分裂／随机轨迹，超过 2048 颗仍可播种，保留营养与空间约束、有限免疫分裂和大病灶几何开局。

## 加速路径与构建

此前 v4 加速验收（透明度／癌前监视更新前）在本机 RTX 4050 / Chrome 实测：640×480、144 颗细胞的纯模型循环，WASM 约 86 MCS/秒，相同 v4 JS 规则约 18.4；最大 768×576、208 颗细胞约 45.6。浏览器含显示实测：288×216 的 0.5×、2×、4×约 15、60、119 MCS/秒；640×480 从 1×约 30 提升至高倍率约 58 MCS/秒。数值随场景和系统负载变化，达到算力上限后不能保证倍率线性增长。

微环境当前使用较粗网格，CPU 常比 GPU 的传输／读回更快，自动模式会如实显示测速结果。GPU 绘图与微环境后端独立；WASM 是 CPU 加速，不是 GPU 形变。所有形变、接触和代谢步仍执行。

普通 `npm run build` 使用随源代码保留的 `build/cpm-kernel.wasm`，并核对 C 源码与二进制哈希。修改 C 后需 `npm run build:wasm`：使用 [官方 WASI SDK](https://github.com/WebAssembly/wasi-sdk) 的 Clang，设置 `WASI_CLANG` 指向可执行文件（或放在 `.tooling/wasi-sdk-20.0+m/bin/clang.exe`）。本次使用 SDK 20 / Clang 16，编译参数记录于 `build/cpm-kernel.meta.json`；浏览器运行不需要编译器。
